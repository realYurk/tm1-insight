TM1 Insight 0.3 — Windows 本地学习工作台

1. 保留整个程序文件夹，双击 TM1 Insight.exe。
2. 初次无模型时显示合成 Demo；进入设置选择已有本地数据库或导入数据包。
3. 在“读懂业务”输入功能关键词，或输入 * 分析整个模型。
4. 阅读方法、输入输出、公式、引用解析、未解释规则与耦合线索。
5. 从 TI 保存经验候选，到“我的经验”补充用途、适用条件和验证记录。
6. 可按需求比较分摊实现方式，或下载语言无关的迁移准备说明。

经验的验证状态是人工记录，软件没有执行服务器测试。模型更新后需复查证据。
软件只读分析，不执行 TI，不上传客户数据，不调用 AI 服务。
程序包不包含任何真实模型、账号、密码或私有教材。

前端文件目录与缓存位置可指定任意盘符，无需复制到 C 盘。
整个用户工作区也可在启动前通过 TM1_INSIGHT_HOME 指定，例如：
set "TM1_INSIGHT_HOME=D:\PrivateTM1Workspace"
"TM1 Insight.exe"

默认用户目录：%LOCALAPPDATA%\TM1 Insight
导入数据、经验和缓存都在用户工作区，升级程序时请保留它。
关闭服务前等待需要保存的评审完成。分析子进程会随主程序退出停止。

不打开浏览器启动："TM1 Insight.exe" web --no-browser
运行程序自检："TM1 Insight.exe" --self-check
端口冲突时选择下一个可用端口，以控制台实际显示的 URL 为准。

当前边界：条件路径不求值，跨过程参数、动态引用和 Rule/Feeder 完整语义仍需复查。
迁移说明不是等价 Java 实现。尚未完成干净 Windows 电脑与所有版本服务器兼容性验收。
“备份当前项目经验”导出当前项目记录和历史；自动恢复导入仍待实现。
