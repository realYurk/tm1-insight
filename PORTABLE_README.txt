============================================================
 TM1 Insight  -  Portable Windows Edition
============================================================

TM1 Insight 是一款 IBM Planning Analytics / TM1 模型理解与运维工具。
本 Portable 版本无需安装 Python 或任何开发环境，解压即可使用。


------------------------------------------------------------
 快速开始
------------------------------------------------------------

1. 解压整个 "TM1 Insight" 文件夹（保持文件夹完整，不要只拷贝 exe）
2. 双击 "TM1 Insight.exe"
3. 浏览器会自动打开本地页面
4. 首次使用请点击「设置 / 配置连接」，填写 TM1 Server 地址与账号
5. 点击「开始拉取」获取模型数据
6. 数据获取后即可浏览 Cube / Process / 依赖关系 / 血缘分析等

如果浏览器没有自动打开，请手动访问启动时控制台窗口里显示的
URL（通常是 http://127.0.0.1:8000）。


------------------------------------------------------------
 关闭程序
------------------------------------------------------------

直接关闭那个黑色的控制台窗口（或按 Ctrl+C）即可停止服务。
程序不会在后台残留进程。


------------------------------------------------------------
 端口说明
------------------------------------------------------------

默认使用 8000 端口。如果 8000 已被其他程序占用，
TM1 Insight 会自动改用 8001、8002……并自动用新端口打开浏览器。


------------------------------------------------------------
 数据与配置存放位置（重要）
------------------------------------------------------------

为方便升级与保护你的数据，TM1 Insight 将「软件」与「数据」分开存放：

  · 软件（程序文件）：你解压出来的 "TM1 Insight" 文件夹
  · 数据（配置 + 模型数据 + 日志）：
       %LOCALAPPDATA%\TM1 Insight\
       （通常是 C:\Users\你的用户名\AppData\Local\TM1 Insight\）

这意味着：
  · 你可以把 "TM1 Insight" 文件夹放在任何位置（桌面、U盘、网络盘）
  · 无需管理员权限
  · 升级软件（替换文件夹）不会丢失你的连接配置和数据

如需把数据也放到指定位置（例如便携 U 盘），可设置环境变量
TM1_INSIGHT_HOME 指向目标目录。


------------------------------------------------------------
 遇到问题？
------------------------------------------------------------

请查看日志文件：
   %LOCALAPPDATA%\TM1 Insight\logs\launcher.log

把日志内容反馈给管理员即可快速定位问题。


------------------------------------------------------------
 系统要求
------------------------------------------------------------

  · Windows 10 / 11（64 位）
  · 无需安装 Python、Node.js、Git 等任何开发环境
  · 无需管理员权限
  · 需要能访问 TM1 Server 的网络连接（获取数据时）
