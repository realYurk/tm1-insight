# 产品工程审查与本轮交付范围

此文件记录可复查的工程结论，不代表已经完成商用产品验收。真实模型与本机测量记录不进入此仓库。

## 已修正

- 关系图 BFS 重复扩展已访问节点，在多条路径汇合的图上会枚举指数级路径。现在每个可达节点只扩展一次；最短路径和稳定排序契约保持不变。合成回归使用 24 层汇合图验证展开次数。
- 菜单曾预取分析页并由 JavaScript 缓存和替换整页，增加无用计算、内存占用和导航竞态。改回原生导航，加点击反馈；重计算对比先返回页面框架。
- 影响分析入口不再为了展示空表单加载完整模型关系；选定对象才使用最多两份模型索引。依赖方和依赖对象明确区分，页面声明结构关系的语义边界。
- 数据源选择原子持久化到用户目录。直接选择任意命名 DuckDB 文件可在重启后恢复；显式选中的本地库不可用时报告错误，不自动改成 Demo。
- 本地目录发现支持唯一候选一键使用、多候选明确选择。ZIP 导入按块复制唯一数据库，先校验独立新目录，再切换；失败不覆盖原库。
- 知识分析使用有界后台任务、取消检查点、源指纹隔离和可重建磁盘缓存。缓存含数据库路径哈希、文件/WAL 状态、范围选项、引擎版本。默认一个工作线程、一个等待任务、32 条任务记录、256 MiB 缓存。
- 结果每页 50 项，API 最大 100 项。任务切换菜单后可以恢复，重复相同分析可以复用磁盘结果，导出复用完成结果。
- 操作观察忽略注释和字符串中的伪函数，保留重复操作、源码段/行/列和内容哈希，重用现有 Parser 处理引用。缺失位置保持未知。
- 稳定候选 ID 基于操作签名，不按发现次序编号。源码顺序不是运行时顺序，读写并存不证明某种业务计算，候选不自动成为最佳实践。
- 新的交互式知识导出默认不包含源码，包含本地私有标识与发布禁令。公开提交检查只允许产品源码、合成测试和文档，并检查本地凭据值及常见密钥。
- 知识工作台使用原生表单、可聚焦控制、进度/错误状态、分页表格、导航标签、明暗主题和减少动画支持。

## 本轮新增：项目学习流程

- “读懂业务”把确定性扫描整理为六步学习 SOP、11 类方法教材、Cube 输入输出地图、TI 调用与有限公式链、待复查事项和去常量结构相似族；保留源码位置与哈希。
- 通用教材模板独立编写、默认禁止运行，不把客户源码发布为模板；只有代码信号的候选不升级为已验证经验。
- 前端来源与工作目录可选择任意可访问盘符，按模型隔离保存；扫描结果写独立侧库，初始化原子完成，失败保留已有结果。Excel 单工作表目前只取前 200 行。
- 启动浏览器由 CLI 唯一负责，批处理删除重复打开动作；代码生成增加错误、等待与重复点击反馈。
- 源码安装的学习扫描通过独立本地进程执行，避免词法扫描争用 Web 线程的 GIL；结束后释放进程内存。现有冻结 exe 使用线程兼容分支，需要单独接入 worker 启动入口并重新发行。CLI `study` 支持离线生成本地私有教材。真实案例教材只留在被忽略的本地缓存，不进入仓库。

## 验证方法

1. 在隔离临时用户目录运行全部 pytest，使用虚构模型验证持久化、失败恢复、后台任务、缓存复用、源切换隔离和安全导入。
2. 浏览器使用独立合成 Demo，检查分析开始反馈、完成结果、分类切换、导航后恢复、比较页面和窄窗口布局。
3. 真实模型只读测量菜单和列表请求；至少一次冷请求及 30 次热请求。仅输出汇总耗时，不输出模型名称、源码或凭据。
4. 比较只读测量前后数据库大小与修改时间，检查暂存文件清单与发布保护脚本后才推送。

后端请求基准不包含浏览器绘制；不能当作 INP 或端到端性能验收。后台任务使用线程仍会竞争 CPU，未来需持续测量并决定是否采用独立进程。

## 发布前仍需完成的工作

- 语义：结构化语法、变量/参数传播、条件与循环、公式中间表示、Rule/Feeder 语义、动态引用缺口。当前有限词法公式链可以提出比例写入候选，仍不能识别或证明完整分摊算法。
- 图：引入带对象类型的节点键，避免同名 Cube/Process 合并；区分结构依赖、值流和运行时调用。保持旧引擎契约，通过新版本迁移。
- 经验包：来源权利、项目隔离、版本、人工评审、适用条件、反例、测试证据、弃用机制。现有候选输出不能替代这些内容。
- 无 AI 推荐：维护有版本的分摊实现目录、显式决策规则与硬约束排除原因；结果必须解释适用性与未知项。尚未实现自动选择最佳分摊方案。
- Java 迁移：选择一个有界功能，建立输入/输出、精度、重跑、并发和失败恢复契约，完成 TM1 与独立实现对照后再扩大范围。没有整服务器自动翻译承诺。
- 数据更新：完整采集和索引构建到新快照、失败保留旧快照、原子切换和晨间调度。当前 ZIP 导入的原子切换不等于在线采集已满足此流程。
- 性能：持续大模型负载、低配置电脑、冷启动、全文搜索、深调用图、大结果缓存分页、分析并发导航与内存稳定性。JSON 磁盘结果当前分页会读取结果文件，仍需按分区存储优化。
- UI：全站键盘和屏幕阅读器审查、搜索请求过期处理、统一空状态、长对象名与复杂图交互、真实端到端反馈分位数。尚未宣称全站符合 WCAG。
- 比较：Web 当前为“空快照到当前目录”预览，并采样最多 50 个 Cube；真正的两个历史快照选择尚未接入页面。
- 发行：干净电脑安装、升级回退、私有数据备份恢复、资源限制、长期支持及发布包隐私审查。本轮未重打包或发布新的 exe。

每一阶段的验收契约见 [PRODUCT.md](PRODUCT.md)。工程测试数量和演示外观不能代替实际项目验证。
