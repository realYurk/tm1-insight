# 独立使用者验收协议（待执行）

对象：至少两名未参与实现的开发者；使用隔离合成快照，不访问企业服务器或业务单元格。主持人只给任务，不指引点击。每位单独记录时间、点击、正确性、误判、失败原因及构建版本。

1. 60 秒内找到目标 Cube 的写入 TI、坐标和源码。
2. 3 分钟内区分一个真实静态 CellGet 值依赖与同 TI 的无关读取；说出动态 Cube 的未确认状态。
3. 找到某 TI 的调用方、直接被调用者、参数和条件；说明调用不证明执行。
4. 从 Cube 血缘移交 25、60、61 项及长名称：前两项无遗漏，超限时明确阻止；检查快照变化和取消后重开。
5. 仅凭 Markdown / JSON 复核常量写入、确认来源、未知来源、Rule 与 Feeder 的语义差异。

当前状态：未安排参与者，所有时长和点击数待记录；不能以实现者、自动化或浏览器截图替代独立验收。
