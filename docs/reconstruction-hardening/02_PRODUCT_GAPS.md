# 02 产品差距

1. Cube：对象共同读写是候选，不回答某个值从哪来；常量写入、动态坐标和外部行数据需要各自解释。
2. TI：调用索引、静态参数和调度定义并非执行记录；跨过程值传播不应默认成立。
3. 模块：当前范围可固定并保留证据，但关键计算、共享依赖及验证缺口仍需开发者确认。
4. Cube 血缘、Functional Flow、Architecture、Module Spec 分别组织相近事实；目前没有完成跨页面和导出一致性验收。
5. UI 图节点预算、图查询预算、源码分析预算与导出范围不同；不得把任何一个当完整模型。
6. 人工任务 A–E 和独立开发者计时尚未组织，不能用作者自测替代。
