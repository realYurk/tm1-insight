# 离线功能交接 v1：完成标志与进度

更新时间：2026-11-03。目标是一个可以结束并交付的版本，不是要求一次完成全部 TM1 语义。

## 用户验收任务

在一台断网电脑上，打开一个已采集的合成模型包，从目标 Cube 或 TI 找到一个功能：看清已采集的维度、形成该结果的主要 TI / Rule、输入和目标切面，打开源码证据，导出一份能交给另一位开发者阅读的功能说明。对无法确认的关系，说明具体缺什么，不能把共同读写当作值流。用户可实际完成这项任务，才可以宣布 v1 完成。

## 六项完成门槛

1. **操作可用、响应可测**：TI 源码优先显示，搜索、复制、行号与返回可用；在事先写明设备和数据规模下实测冷/热首屏与长源码交互，记录 P50/P95，未达到路线目标则不得称性能验收通过。
2. **结论一致**：合成模型覆盖常量、已确认值依赖、共同读写、动态目标、Rule 与 Feeder；Cube、血缘、功能说明及导出对方向、状态和证据一致。
3. **资料可带走**：离线包有版本、清单、校验和、明确范围与缺失项；在新目录断网导入并搜索、查看源码和结构；异常包不覆盖原数据。摘要不得称为完整定义。
4. **功能可以交接**：至少一个有界功能包含入口、对象、维度、输入、写入切面、规则、外部依赖、源码和可操作缺口；范围截断可见。
5. **他人能完成**：两位未参与实现的开发者独立使用合成包完成固定任务，记录耗时、步骤和误判；未完成时此项待验收。
6. **回归和安全**：离线全量测试通过；旧 API 和快照兼容；不连接企业服务器、不修改正式数据库；发布包不包含凭据及默认业务单元格。

六项都通过后，宣布“离线功能交接 v1 完成”，停止本轮目标并交用户验收。完整服务器恢复、全部动态语义、自动确认业务意图与运行等价不在 v1 完成范围；后续需求单独立项。

## 当前状态

- 第 1 项：**进行中**。源码、调用树按需及长源码分批能力已有实现；本次默认打开首个非空源码段。真实浏览器性能与全部交互门槛尚未完成验收。
- 第 2 项：**部分实现，待跨视图验收**。已有静态来源保守判断，不能据此宣称所有页面一致。
- 第 3 项：**进行中**。分析包已加入阅读说明，缺失维度字段和成员数不一致不再标为完整；可在业务架构页面选择 ZIP 校验，也可用 `tm1-insight verify-analysis-package <ZIP>` 离线核对清单和校验和。校验不证明来源可信或资料完整；维度仍可能是采样摘要，离线导入及独立环境验收待完成。
- 第 4 项：**部分实现，待端到端验收**。已有模块规格与功能报告，尚未证明离线完整交接闭环。
- 第 5 项：**待完成**。已有验收协议，未有两位独立开发者结果。
- 第 6 项：**持续检查，最终待验收**。每次提交记录测试；一次通过不能代替最终版本验收。
