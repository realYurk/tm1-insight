# 资产分页与按步骤生成草稿（2026-10-13）

## 1. 产品结果与范围

对应用户反馈 13、14、6，服务 Govern / Prove / Modernize：从大量前端资产找到引用对象，核对 Cube 维度顺序，再生成可供人工验证的 TI 草稿。

最小闭环：全量搜索/筛选 → 分页定位资产或映射 → 查看 Cube 完整维度名称；选择源/目标 Cube → 加载结构 → 配置筛选 → 生成草稿 → 区分同名坐标候选与未知映射。

本轮不包含数值等价证明、执行 TI、业务目的推断、快照管理、工作流语义引擎或新发行 exe。

## 2. 检查到的代码事实

- 原 `/audit` 调用两个全量查询，加载所有资产和映射到 Python 与 HTML，搜索/风险过滤只操作页面上的行。
- 原数据传输表单并列放置加载与生成按钮，没有维护已加载 Cube 对及数据源状态；未加载时也可能生成无筛选草稿。
- `_cube_dims` 从 `cube_has_dimension` 按 `dim_order` 读取；`data_transfer` 仅以维度名称相同生成坐标复用候选，缺失项生成空值。它不能证明业务映射或运行结果。
- 原维度名称列上限 300px，单行省略；元素区域还通过脚本隐藏放不下的示例。
- 原维度联想初始化早于请求函数定义，错误被吞掉，可能导致维度下拉没有数据。

## 3. 实现与文件

- `store/queries.py`：新增 `audit_page`、`audit_summary`。参数化字面量搜索，先筛选再分页；SQL 聚合总量，Python 只获取一页；稳定排序、越界页归一化，查询层上限 100 条。保留原全量函数供旧调用者使用。
- `api/app.py`：`/audit` 两表独立分页，每页 50 条；URL 保留另一表的条件与页码。页面来源指纹涵盖模型与扫描侧库，旧来源返回 409。生成 API 增加可选结构上下文并核对源/目标维度顺序与模型指纹；缺少结构记录、错误维度筛选、不支持的操作返回 400；过期或请求期间换源返回 409。
- `templates/audit.html`、`audit_pagination.html`：全量搜索和组合筛选表单、页码/范围/过滤数量、明确空结果提示，缺失风险标记为未评级。保留扫描进度、取消和目录保存。
- `templates/codegen.html`、`static/codegen-transfer.js`：分步操作、加载/生成中禁用按钮、更换 Cube 清除旧结构和草稿、输入变化丢弃在途结果、浏览器返回缓存时重新核对；错误可恢复。结构证据与 UNKNOWN 明确展示。分段按钮使用单一处理器，重复生成不重复绑定；维度联想延后初始化。
- `templates/cube_view.html`、`static/style.css`：维度名称约占结构行 53%，允许换行；最多五个元素示例换行保留，窄屏上下排列。写入明细增加局部横向滚动容器。
- `tests/test_audit_pagination_codegen.py`：合成数据库覆盖分页、跨页搜索、组合筛选、来源隔离、结构变化、请求中换源、旧 API、未知映射及原库哈希保护。

不增加依赖、不改数据库模式。回滚可以还原本次代码提交，无数据迁移。

## 4. 可复查的证据示例

合成数据包含 1128 个资产及 1128 条映射。第一页每表只有 50 行；完整遍历 23 页无重复遗漏。搜索 `file-1127` 或 `Only Last Cube` 可直接定位末条记录。映射仍是扫描/存储记录，不能据此宣称已验证业务计算。

## 6. 兼容性、安全与性能

旧 API 调用可以不传新增 `structure`，仍使用当前元数据生成。Web 交互始终提交该上下文。有效既有请求保持兼容；原先缺少维度也生成空壳代码的无效请求现在明确报错。

Web 资产页最多渲染两组各 50 行；计数、搜索和排序在 DuckDB 中执行。深页使用 OFFSET，仍需数据库扫描/排序，并非恒定时间索引查询。没有把分页误实现为全部读出后切片。

分析连接只读，扫描仍沿用独立侧库。测试不连接真实 TM1、不执行生成的 TI，也不修改现有业务数据。来源指纹只用于失效判断，不代表完整快照版本或内容级证明。

## 7. UNKNOWN 与限制

- 草稿仍依赖既有日志/Bedrock 框架，包含清目标及写入操作；必须核对范围、参数、数据源变量、未知映射并在隔离模型验证，不能宣称可直接执行或等价迁移。
- 名称相同不证明元素语义相同；动态转换、层级、Rule/Feeder 及运行时数值验证仍未实现。
- 资产映射继续使用既有存储表示和每张表前 200 行扫描范围；本轮不提高引用解析覆盖度，也不修复历史数据缺失。
- 不提供页大小选择、完整快照版本管理或多实例任务协调。更新源码不会自动更新旧 exe。
