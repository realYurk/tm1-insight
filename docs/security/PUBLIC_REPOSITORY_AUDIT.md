# 公开仓库安全审计（2026-10-21）

> 范围：`master`、`codex/product-evolution-01`、`codex/visual-development-02`、当前本地分支
> 方法：`git grep`（按 HEAD 与历史对象）、`git log --all -- <path>`、凭据形态正则、人工复核分类。
> 本文**不复制**敏感原文，只给文件、类别与处置建议。

## 1. 结论摘要

| 类别 | 发现 | 是否需要立即处置 |
|---|---|---|
| A. 凭据 / Token / 私钥 / 证书 | **未发现**（`.env`、私钥、云 Token 均从未进入历史） | 否 |
| B. 企业/客户专有源码或数据文件 | **未发现**（DuckDB / parquet / WAL 从未提交） | 否 |
| C. 企业模型对象名称 / 业务术语 | **存在**：9 个文件（`master` 既有） | 需授权判断 |
| D. 通用技术材料 / 合成示例 | 大量，属正常内容 | 否 |
| E. 本机绝对路径 / 个人环境信息 | **存在**：2 份文档（`master` 既有） | 建议整改 |

**不存在可直接导致账号或数据被访问的凭据泄露**，因此不需要凭据轮换。
但 **C、E 两类属于"技术脱敏"问题，不等于已获得公开发布授权**。

## 2. A 类：凭据

扫描覆盖：`.env`、`*.pem/*.key`、云厂商 Token 形态、私钥头、`password/secret/token` 赋值。

- 历史查询 `git log --all -- .env` → 无记录。
- `-----BEGIN ... PRIVATE KEY-----` 仅命中仓库自带的发布检查脚本 `scripts/check_publication.py` 中的**正则定义**，不是密钥。
- `README`、`docs` 中的 `TM1_PASSWORD=你的密码` 为占位示例。

**判断：无凭据泄露，无需轮换。** 若未来在历史中发现真实凭据，仅删除分支无效，必须轮换并评估暴露窗口。

## 3. C 类：企业模型对象名称

`master` 上有 **9 个文件**包含真实模型对象名（测试夹具、示例文档、模板占位、查询代码）。本轮新增分支已全部改用合成名称（`SalesCost` / `Planning PnL` / `Sales Cost Driver`），并把真实名称改为运行期环境变量传入。

风险性质：

- 这些是**对象名称**，不含单元格数值、不含 Rule/TI 源码正文、不含连接信息。
- 但名称本身可能反映业务结构，是否可公开取决于企业授权，**不能由技术扫描替代**。

处置建议（需用户决定）：

1. 首选：将仓库**暂时设为私有**，待确认授权后再评估公开范围。
2. 若要长期公开：对 `master` 历史做一次受控清理（改写历史 + 强推），并通知所有克隆方重新拉取；
   这会改变既有提交 SHA，属于不可逆操作，**必须由用户明确批准后执行**。
3. 折中：保留历史，但在 `README` 明确声明仓库为内部开发仓库、示例为脱敏占位，并停止继续新增真实名称。

## 4. E 类：本机绝对路径

2 份较早文档包含 `D:/…` 形式的本机路径（用于复现采集命令）。风险：暴露本机目录结构与项目代号，不涉及凭据。

建议：改为相对路径或 `<workdir>` 占位；历史中的旧版本无法通过删除分支消除。

## 5. 已确认未发生的风险

| 检查 | 结果 |
|---|---|
| `.env` / 凭据文件进入历史 | 否 |
| DuckDB / parquet / WAL 进入历史 | 否 |
| 构建产物（`dist/`、`release/`）被跟踪 | 否（`.gitignore` 覆盖） |
| 交接备份目录被跟踪 | 否（位于仓库之外） |
| 用户工作区 / 资产库被跟踪 | 否（`workspaces/`、`assets/` 已忽略） |

本轮补充：`.gitignore` 增加 `assets/`（工程资产为个人数据，不入库、不分发）。

## 6. 本轮采取的推送策略

任务书要求「历史暴露未评估清楚前不自动推送新内容」。因此：

- 本轮所有开发提交保留在**本地分支** `codex/engineering-asset-3`。
- 未推送、未合并 `master`、未改写任何历史、未删除任何远程分支。

## 7. 需要用户确认的动作

| 编号 | 动作 | 影响 |
|---|---|---|
| S1 | 是否将仓库设为私有 | 可逆，立即降低暴露面 |
| S2 | 是否清理 `master` 历史中的对象名与绝对路径 | 不可逆（改写 SHA），需通知克隆方 |
| S3 | 是否授权推送本轮分支 | 会把新增资产功能公开 |
| S4 | 确认 C 类对象名是否具备公开授权 | 法律/合规判断，技术无法替代 |

在 S3、S4 明确前，本轮不推送。
