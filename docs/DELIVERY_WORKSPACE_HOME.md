# 工作台首页与系统入口（2026-10-14）

## 1. 产品结果与支柱

对应反馈 7 / 11 / 12 / 16。首页以定位计算和核对证据为主，减少重复对象规模展示；连接与版本入口归到「系统与数据」。这改善 Reverse Engineer / Prove 的进入路径与 M6 的可用性，不新增业务语义引擎。

范围：首页结构、全站侧栏配色和分组、首页搜索、快照页默认状态。非目标：真实历史版本管理、跨 TI 工作流提炼、数值验证或迁移执行。

验收：原搜索与 MDX 反查可用；首页可进入 TI 计算检查；目录统计保留；Local / Demo 来源显示保持真实；快照默认页不构图、不列伪变更；移动端无横向溢出；旧比较引擎测试保留。

## 2. 检查到的实际代码

- `templates/index.html` 原首页包含任务卡、状态卡、搜索、MDX 大卡和多色统计卡，重复呈现规模和入口。
- `api/app.py:index` 用数据库文件 mtime 显示「快照时间」，不能证明实际采集时间；还枚举快照目录，但页面不能选择这些版本。
- `/compare` 原默认加载脚本自动请求 `render=true`。后者用空基线与当前目录比较，再采样最多 50 个 Cube 做结构影响预览；不是两个历史版本的变化。
- `store/queries.py:search_objects` 原用 ILIKE，名称中 `%` / `_` 被当成通配符；首页结果将对象名直接拼入 HTML。
- `base.html` 已有数据源状态和主题切换。沿用来源检测、设置、对象浏览、MDX 和计算检查接口。

## 3. 实现与文件

- `templates/workbench_home.html`：搜索主区、三个证据核对步骤、可展开的 MDX、工具链接、单条目录统计带；空模型保留导入和设置入口。
- `templates/index.html`、`static/home.js`：脚本从模板移出；保留导入和 MDX 操作。搜索取消旧请求并检查请求序号，清空或关闭结果后 Enter 不会打开隐藏候选。结果使用文本节点；MDX 输出转义名称、成员和条件，避免 HTML 注入。
- `static/workbench.css`：柔和灰绿侧栏、深色主题配套、清晰选中态；首页使用留白、分隔线和列表，不再堆叠彩色卡片；窄屏上下排版。
- `templates/base.html`：连接设置、快照与版本位于「系统与数据」；计算检查页高亮 TI 所属菜单。
- `templates/compare_status.html`、`compare.html`、`api/app.py`：默认快照页只说明能力边界，技术预览需显式打开；保留 `/compare?render=true` 及引擎行为，并强调 ADDED 只是空基线的结果。
- `api/app.py:index`：移除无用途的快照计数枚举；mtime 更名为文件修改时间。仅有 TI / 维度等对象的模型也视为有数据。
- `queries.py:search_objects`：名称字面包含，精确名称优先，其次前缀，结果有上限。API 查询最长 1000 字符，每类最多 50 个，默认 20 个；响应结构保持三个名称数组。
- `tests/test_datasource_api.py`：默认快照页不进入重计算、显式技术预览兼容、名称特殊字符、排除代码引用命中、请求预算。

## 4. 证据核对路径

合成 Demo：首页输入 `Load` → 打开 `Load_Sales` →「计算检查」→ 目标坐标与源码位置。没有已知定义的数据源变量仍显示 UNKNOWN；首页不会声称理解了这些变量的业务含义。

合成搜索 `Example_100%` 只返回该名称，排除 `ExampleX100Z` 与源码中调用它的 `Caller`。MDX 中的 `Example <img src=x>` 显示为文字，浏览器确认结果区没有 img 元素。

## 6. 兼容、安全与性能

不改数据库模式，不增加依赖，不删除数据，不执行 TI，不连接服务器。首页不再枚举历史快照目录；默认快照页不构建模型图或比较结果。全局搜索只返回受限的名称列表，不读取源码。

原 `/compare?render=true`、MDX、导入、设置及对象路由保留。全局搜索有意将 SQL 通配符改为字面字符，超预算请求返回 422。统计仍来自当前目录，不把数量解释为理解率。

用户原服务和浏览器页保持运行；验证使用独立临时目录和端口，结束后停止。源码升级后需重新启动原服务，才会加载新的 Python 路由。

## 7. UNKNOWN 与限制

没有历史快照创建/选择/比较闭环，因此默认页明确说明尚未接入。原技术预览仅用于开发核对，不能证明真实新增、删除、修改或数值影响。

文件修改时间不是服务器采集时间。MDX 候选分数不是运行证明，关联读取 Cube 不是值流；零候选不能证明没有其他写入。首页没有自动验证业务解释，也没有生成跨过程算法。

## 8. 下一项建议

继续第 8 / 15 点：对一个明确入口和一个子 TI，连接显式参数绑定、使用位置与读写坐标，保留动态参数和控制路径 UNKNOWN；让工作台进入可核对的跨过程功能范围。
