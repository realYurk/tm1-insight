# 画布主导、渐进披露

默认只显示工作区栏、搜索、少量视图操作、画布和收起的底部 Dock。无入口时提供开始探索的空态，而非虚构默认业务链。对象搜索后进入局部图，资源栏自动收起；用户可以再次打开。

## 操作层次

1. 搜索 Cube / TI / Rule 所属 Cube，查看实际局部关系。
2. 点击节点或边：打开轻量概览。Cube 显示实际维度数和当前范围输入输出；TI 显示读取、写入、操作方式及切面；Rule 连线显示目标区域、可确认的 DB 来源和规则数量。
3. “源码与证据”：按需展开完整源码、逐写入点、IR 和未确认原因。关闭详情不重建图、不清空选择。
4. 右上角“＋ 创建”：Cube 草稿、CSV Schema、设计关系、维度草稿、人工模块。内部保留既有 design.mode 数据字段和能力，不再要求用户先理解顶层探索 / 设计切换。

Cube 草稿创建直接复用现有 `addCubeDraft/editCubeDraft`，不新增生成器。CSV 是用户声明的表头草稿，不读取文件。SQL 创建未添加伪入口。既有设计关系校验、模板生成和工作区保存保留；生成草案不代表部署或运行验证。

## 布局与反馈

- 默认 LR 分层；支持 TB，方向写入既有 `layout.vertical`。
- 保留 Tarjan SCC、最长路径层次和重心排序；高连接节点不再默认环绕。
- SCC 成员在同层错位，不伪造其内部执行顺序。层间箭头保留真实方向；循环允许回边。
- 显式自动布局可以覆盖位置；详情切换、过滤、局部扩展不应覆盖已有手工位置。
- Cube 沿用蓝色图标，草稿沿用暖色；TI 改为流程图标，避免与 Cube 混淆。长名称继续使用原悬停全文与详情标题。
- 删除 Cytoscape 核心大圆形点击反馈。保留克制的选中边框和语义边色。
- CSS 与 JS 聚焦动画都响应 `prefers-reduced-motion`。

“共同读写”只表达 TI 对象级关联；切面摘要是观察值集合，不把并集解释为所有写入共享切面。Rule 是声明式引用，Feeder 不是数值贡献。缺失源切面不由目标切面反推。

## 边界

本轮没有承诺完成全部长期愿景。外部业务库、企业数据、SQL Schema 自动发现、自动部署均不在范围内。原工作区持久化和模板接口已有实现，应继续复用，而不是让后续工程师再造一套。
